## Local arm64-only release build (this Linux box)
No Node/JDK on PATH by default. Toolchain installed under `/tmp/opencode/`:
- JDK 17 Temurin: `/tmp/opencode/jdk17` (JAVA_HOME)
- Node 22: `/tmp/opencode/node22` (for the RN JS bundle step)
- `ANDROID_HOME=/home/userver/android-sdk`
- Build command:
  ```
  cd android && ANDROID_HOME=/home/userver/android-sdk JAVA_HOME=/tmp/opencode/jdk17 \
  SENTRY_DISABLE_AUTO_UPLOAD=true \
  PATH="/tmp/opencode/jdk17/bin:/tmp/opencode/node22/bin:$PATH" \
  ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a --console=plain
  ```
- `-PreactNativeArchitectures=arm64-v8a` overrides `reactNativeArchitectures` in `android/gradle.properties` (all ABIs) → APK contains ONLY `arm64-v8a` (verified via `aapt2 dump badging` → `native-code: 'arm64-v8a'`).
- `SENTRY_DISABLE_AUTO_UPLOAD=true` required, else `createBundleReleaseJsAndAssets_SentryUpload_*` fails (no `SENTRY_AUTH_TOKEN` here).
- Output: `android/app/build/outputs/apk/release/app-release.apk` (~38 MB).
- Typecheck: `PATH="/tmp/opencode/node22/bin:$PATH" node node_modules/typescript/bin/tsc --noEmit`.

## Delivering the APK over SMB
- Target: `smb://192.168.1.124/Sharing/UMUM/VINCENT/` as `opencode-theme-arm64.apk`.
- The local `/srv/samba/shared` path is read-only for `userver` and `sudo` needs a password → use the network share instead.
- Anonymous SMB can LIST but not PUT. Working command (user `admin`, password `admin`):
  ```
  smbclient //192.168.1.124/Sharing -U admin%admin --timeout=60 \
    -c 'cd UMUM/VINCENT; put <apk> opencode-theme-arm64.apk'
  ```
- NOTE: use backslash or `cd ...; put` — `smbclient` positional `ls UMUM/VINCENT/` mis-lists; `cd UMUM; ls` works reliably.
